## Entry

The whole internet, in a single word: a maze built out of browser tabs.
Every tab is another corridor, every link another turn, and nobody
remembers where they entered — yet everybody keeps wandering deeper.
One coined word, nine letters, readable at first sight.

## Run it

```sh
node main.ts
```

This prints the word to stdout and writes the exact same word to
`/output/entry.txt` (UTF-8, 9 characters, a single word with no spaces).
